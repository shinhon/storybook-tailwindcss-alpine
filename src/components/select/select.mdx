## Portable source

Select is a behavioral component. Its custom renderer produces the portable
Alpine HTML, while `select.ts` provides the Alpine behavior and provider that
manage its interaction state.

Register the provider before calling `Alpine.start()` when adapting these
sources for a standalone HTML environment.
